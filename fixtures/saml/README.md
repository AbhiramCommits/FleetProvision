# SAML fixtures

`valid.xml` is a signed SAML 2.0 Response used by `fleetd::saml` tests and
`fleetctl saml verify`. The invalid fixtures are `expired.xml`,
`wrong-audience.xml`, `unsigned.xml`, and `replayed.xml` (same assertion as
`valid.xml`, used to assert replay rejection).

`idp-key.pem` is a **test-only** RSA key generated by
`scripts/gen-saml-fixtures.py`; never use it outside tests. Regenerating the
fixtures requires `pip install signxml cryptography`.
